# Runtime dependencies for the inference API on Linux + NVIDIA GPUs.
#
# The existing requirements.txt is a win-64 conda spec for Python 3.8 and does
# not resolve on Linux. This file pins the set the service actually runs on.
#
# Install into a Python 3.10 environment:
#
#   conda create -y -n extract_areas -c conda-forge python=3.10
#   pip install -r requirements-linux-gpu.txt
#
# Two dependencies are not installable from this file:
#
#   1. SAM2 is built from source (the sam-2 PyPI package is stale):
#        git clone https://github.com/facebookresearch/sam2.git module/sam2
#        SAM2_BUILD_CUDA=0 pip install -e module/sam2
#
#   2. DeepLIIF is imported from the git submodule (module/DeepLiff) via
#      sys.path, so it is never pip installed. Its own setup.py pins
#      torchvision==0.10.0, which conflicts with SAM2's torch>=2.5.1
#      requirement; only its runtime deps are listed below.
#
# python-javabridge compiles against a JDK and needs JAVA_HOME at build and run
# time (DeepLIIF imports bioformats at module load):
#   sudo apt install openjdk-11-jdk
#   JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64 pip install --no-build-isolation python-javabridge==4.0.4
